# Модель

Сама нейросеть, которая даёт интеллект системе: **Claude, GPT, Codex** или другая
агентная система. Без [[Память|контекста]] модель ничего о вас не знает.

## Текущая конфигурация
- Основная: **Claude Opus 4.8 / Sonnet** (через Claude Code / Cowork)
- Роль: рассуждение, сборка артефактов-дашбордов, работа с [[Коннекторы|коннекторами]]

## Связи
- Получает контекст из → [[Память]]
- Действует по → [[Правила и скиллы]]
- Дотягивается до данных через → [[Коннекторы]] / [[MCP]]
- Рисует результат в → [[Визуальный слой]]
