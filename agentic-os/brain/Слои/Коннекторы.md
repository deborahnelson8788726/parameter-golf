# Коннекторы

Доступ агента к сервисам через **[[MCP]]**: подтягивают актуальные данные
автоматически, чтобы [[Модель]] работала с живым контекстом.

## Доступные коннекторы
| Коннектор | Статус | Питает виджет |
|---|---|---|
| [[Obsidian-коннектор\|Obsidian]] | ✅ вкл | [[Память]] |
| [[GitHub-коннектор\|GitHub]] | ✅ вкл | [[Входящее]] |
| [[MCP]] (trinity-rag) | ✅ вкл | [[Что нового в AI]], [[Сегодня]] |
| [[Google Drive-коннектор\|Google Drive]] | ⭕ выкл | [[Память]] |
| [[Календарь-коннектор\|Календарь]] | ⭕ выкл | [[Сегодня]] |
| [[Почта-коннектор\|Почта]] | ⭕ выкл | [[Входящее]] |
| [[Notion-коннектор\|Notion]] | ⭕ выкл | [[Мои метрики]] |

На дашборде коннекторы переключаются кликом (состояние сохраняется).
