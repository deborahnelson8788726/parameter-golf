# 8 шагов настройки агентной ОС

1. **Выбрать задачу** — один понятный сценарий (личный дашборд / бизнес / здоровье / задачи). Не охватывай всё сразу.
2. **Выбрать рабочую директорию** — ставь ОС туда, где уже лежит контекст. Тут это `agentic-os/`.
3. **Подготовить память** — собери описание, правила, документы, метрики, структуру папок → слой [[Память]] (этот vault).
4. **Подключить коннекторы** — Notion, Drive, календарь, почта, [[Obsidian-коннектор|Obsidian]], [[GitHub-коннектор|GitHub]] через [[MCP]] → [[Коннекторы]].
5. **Описать виджеты** — начни с 4: [[Сегодня]], [[Мои метрики]], [[Входящее]], [[Что нового в AI]]. Каждый читается за 10 секунд.
6. **Отправить черновик в улучшатель промптов** — сложную задачу сначала в улучшатель → техзадание для Claude Code. См. [[Промпт — утренний дашборд]].
7. **Собрать первый артефакт-дашборд** — только просмотр, без кнопок и логики → [[Визуальный слой]].
8. **Проверить и доработать** — подтягиваются ли данные, не перегружен ли интерфейс, видно ли главное.
