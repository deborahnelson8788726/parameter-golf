# MCP (Model Context Protocol)

Стандарт, по которому [[Модель]] вызывает типизированные инструменты по JSON-RPC.
Каждый инструмент объявляет свои входы, поэтому модель не может прислать
некорректный запрос. Это «провод» всех [[Коннекторы|коннекторов]].

## Наш сервер
- [[trios-mcp-rag]] — RAG over Postgres, 5 инструментов
- Демо-стартер: `trinity-mcp/mcp-starter/` (SQLite-fallback, audit-log, read-only режим)

## Транспорты
- **stdio** — сервер запускается локально рядом с клиентом (Claude Desktop / Cursor)
- **streamable-http** — сервер хостится удалённо (Railway), клиент ходит по URL
