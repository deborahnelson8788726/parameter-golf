# Agentic OS — командный центр Trinity

Реализация проекта из гайда «Как собрать агентную ОС»: **визуальный слой** для
управления всеми модулями + **мозг в Obsidian** как слой памяти.

```
agentic-os/
├── dashboard/        ← сайт (визуальный слой): единый экран управления
│   ├── index.html
│   ├── styles.css
│   ├── app.js
│   └── config.js     ← данные модулей/коннекторов/виджетов (правьте здесь)
└── brain/            ← Obsidian-vault (слой «Память»), связанные заметки
    ├── Agentic OS.md ← домашняя карта (открой Graph view)
    ├── Слои/ Коннекторы/ Виджеты/ Настройка/ Промпты/ Модули/
```

## 5 слоёв (из гайда)
**Модель** (Claude) → **Память** (этот brain + Postgres) → **Правила и скиллы**
(CLAUDE.md) → **Коннекторы** (Notion/Drive/Calendar/Mail/GitHub/Obsidian через
MCP) → **Визуальный слой** (этот дашборд).

## Запустить дашборд
```bash
cd agentic-os/dashboard && python3 -m http.server 8080   # → http://localhost:8080
```
Открывается тёмный экран: слои системы, коннекторы (кликом вкл/выкл, состояние
сохраняется), модули экосистемы, и 4 виджета — **Сегодня · Мои метрики ·
Входящее · Что нового в AI** — плюс поле **«Фокус дня»** сверху. По задумке
данные подтягиваются при каждом открытии и читаются за 10 секунд.

## Открыть мозг
Открой папку `agentic-os/brain/` как vault в **Obsidian** → начни с
`Agentic OS.md` и включи **Graph view**, чтобы увидеть все связи. Всё соединено
`[[wiki-ссылками]]`: слои ↔ коннекторы ↔ виджеты ↔ модули.

## Как обновлять
- **Меняешь что видно на дашборде** → правишь `dashboard/config.js`.
- **Подключаешь живые данные** → каждый виджет имеет поле `source` (какой MCP-
  коннектор его питает). Замени статичные массивы на запросы к [[trios-mcp-rag]].
- **Растёт проект** → добавляй заметки в `brain/` и блоки в `config.js`.

## Принципы (держим дисциплину)
- Один сценарий за раз. Сначала обзор, потом действия.
- Тёмная тема, чистые карточки, 10 секунд на чтение.
- Хаотичная память → хаотичная ОС. Brain держим в порядке.
